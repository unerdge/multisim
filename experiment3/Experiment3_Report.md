# 实验三仿真说明

## 实验内容

依据 `D:\vscode\multisim\ExperimentGuide.pdf` 实验三“互感电压测试及最大功率传输”部分，完成了自感测量、开路互感电压、串联法、耦合系数及最大功率传输的仿真。

## 仿真设置

- 自感：1 Vrms、10 kHz；空心等效线圈 L=10 µH、R=10 Ω，磁环等效线圈 L=100 µH、R=100 Ω。
- 互感：采用 NI Multisim TransformerModels 耦合电感模型，L1=100 µH、L2=25 µH、耦合系数 k=0.8，设计互感 M=40 µH。
- 最大功率：300 Hz、1 Vrms 等效源，负载扫描 10、25、50、100、200、400、800、1200、1600、2000 Ω。

## 主要结果

| 项目 | 结果 |
|---|---:|
| 空心等效线圈测量 L | 10.128 µH（误差 +1.28%） |
| 磁环等效线圈测量 L | 101.282 µH（误差 +1.28%） |
| 串联正向等效 L | 205.030 µH |
| 串联反向等效 L | 45.522 µH |
| 由串联法得到 M | 39.877 µH |
| 耦合系数 k | 0.8000 |
| 最大功率负载 | 25 Ω |
| 最大负载功率 | 2.261 mW |

## 文件说明

`experiment3` 文件夹内包含 6 个可重新打开的 `.ms14` 电路；`data` 文件夹内包含 18 个案例的 CSV 时域数据、汇总 CSV 和 JSON；`Experiment3_Simulation_Data.xlsx` 包含带公式的汇总表、最大功率扫描表和文件清单。

## 说明与限制

互感开路法导出的 CSV 使用 RMS 量，因此正向/反向模型的互感电压幅值相同，无法单凭 RMS 符号判断同名端；同名端判定应在 Multisim 示波器上结合相位/极性观察。耦合部分使用 NI 官方 TransformerModels 样例中的耦合电感模型，属于可复现的理想化等效模型。
